# Array Programs

This folder contains fundamental array manipulation and operations programs in Java.

## Programs Included

### Finding Elements
- **largestelement.java** - Find the largest element in an array
- **smallestnumber.java** - Find the smallest element in an array

### Sum & Average
- **SumOfElementsArray.java** - Calculate sum of array elements (with user input)
- **sumofelements.java** - Calculate sum of array elements
- **averageelements.java** - Calculate average of array elements

### Search & Traversal
- **searchofelement.java** - Search for an element in an array
- **Searching.java** - Search with index return
- **reversearr.java** - Reverse and display array
- **Traversal.java** - Traverse linked list

### Array Manipulation
- **Insertion.java** - Insert element at specific position
- **Updation.java** - Update element at index
- **MoveZerostoRight.java** - Move all zeros to right
- **UnionOf2Arrays.java** - Find union of two arrays
- **CountOfUniqueElements.java** - Count unique elements

### Sorting
- **Sorting.java** - Sort array in ascending order
- **SortingandReverseSorting.java** - Sort ascending and descending

### Patterns & 2D Arrays
- **alernate01.java** - Generate alternating 0s and 1s
- **square0and1.java** - Create checkerboard pattern
- **twomatrix.java** - 2D matrix operations

### ArrayList Operations
- **FrndsArrayList.java** - ArrayList add/remove operations
- **Update3rdValueinArrayList.java** - Update specific ArrayList element

## How to Run

```bash
javac FileName.java
java FileName
```

Each program demonstrates basic DSA (Data Structures & Algorithms) concepts for working with arrays.
